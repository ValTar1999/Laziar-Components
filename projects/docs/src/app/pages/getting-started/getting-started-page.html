Getting Started

Laziar Components

Общая UI-библиотека для publikator и agora-frontend. Документация — витрина самой библиотеки: токены, тема и компоненты в одном месте.

Установка

npm install @laziar/components

Быстрый старт

  1. Подключите @laziar/components/styles/theme.css в глобальные стили.
  2. Инжектните ThemeService для light / dark / auto.
  3. Импортируйте компоненты из @laziar/components.

Подробнее о токенах — Theming. Каркас страницы компонента — Stub.
